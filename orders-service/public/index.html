CS543 Faculty Protocol Lab

One-click live tests demonstrating the exact Web Services requirements demanded by Dr. Pramit Mazumdar.

A04 Task C7 / A05 C3 201 Cached

Safe Retry (Idempotency-Key)

Sends identical POST twice with same Idempotency-Key. Proves server caches response and creates 0 duplicate orders.

A05 Tasks B4, C1 304 Not Modified

Conditional Read (If-None-Match)

Queries order with matching ETag. Demonstrates HTTP 304 response with zero body bytes transferred.

A05 Task C2 412 Precondition Failed

Lost Update Prevention (If-Match)

Sends PATCH with a stale ETag. Server rejects modification to prevent concurrent overwriting.

A06 Tasks B3, C2 422 Problem Details

Multi-Field Validation Error

Sends empty address and quantity 0. Collects all errors into RFC 7807 errors[] list before rejecting.

A05 Task A2 / A3 202 Accepted

Action Sub-Resource Cancellation

Invokes POST /orders/:id/cancel. Returns 202 Accepted initially and 200 OK if retried (safe transition).

Content Negotiation (Accept: XML)

Demands application/xml. Server serializes the same internal Order record into valid XML.
